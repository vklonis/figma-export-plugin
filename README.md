# BannerForge Figma Plugin

Export Figma frames to BannerForge-compatible JSON or self-contained HTML.

## Features

- Export any frame from Figma as **JSON**, **HTML**, or **both**
- Multi-frame batch export with progress tracking
- Complete layer hierarchy (frames, groups, components, instances)
- All typography: fonts, sizes, weights, alignment, letter spacing, line height, text case, decoration
- Colors, gradients (linear, radial, angular, diamond), fills, strokes
- Absolute positioning relative to the parent frame
- Rotation, effects (drop shadow, inner shadow, layer blur, background blur), blend modes
- Image fills exported as base64 PNG at display size (not original upload resolution)
- Vector shapes, stars, lines, polygons, boolean operations — rasterized to PNG
- Partial arc ellipses (arcData) — rasterized to PNG (CSS cannot represent arcs)
- Nested frames and groups with correct coordinate handling
- Component instances (children exported recursively)
- Correct `clipsContent` handling — containers only clip when Figma says so
- No rate limits, no authentication, no network required

## Installation

### Development Mode

1. **Build the plugin:**
   ```bash
   cd figma-plugin
   npm install
   npm run build
   ```

2. **Import in Figma:**
   - Open Figma Desktop App
   - Go to Menu → Plugins → Development → Import plugin from manifest...
   - Select `figma-plugin/manifest.json`

3. **Run the plugin:**
   - Right-click on canvas → Plugins → Development → BannerForge Export

### Auto-rebuild during development

```bash
npm run build
```
TypeScript watch mode: recompiles `code.ts` → `code.js` on save.

## Usage

1. **Run the plugin** from the Figma plugins menu
2. **Select frames** to export (multi-select supported)
3. **Choose format**: JSON, HTML, or Both
4. **Click Export** — files download automatically

### JSON output

Used by BannerForge to reconstruct designs in the editor. Import via "Import from Figma Plugin" in the web app.

### HTML output

Self-contained HTML file using CSS absolute positioning to visually reproduce the Figma design. Suitable for quick visual QA and browser rendering checks. Images are embedded as base64.

## Export Format

```json
{
  "meta": {
    "pluginVersion": "1.0.0",
    "exportDate": "2026-02-08T...",
    "figmaFileKey": "abc123",
    "figmaFileName": "My Design File"
  },
  "frames": [
    {
      "id": "123:456",
      "name": "Banner 728x90",
      "width": 728,
      "height": 90,
      "backgroundColor": "#FFFFFF",
      "nodes": [
        {
          "id": "123:457",
          "type": "RECTANGLE",
          "x": 0, "y": 0, "width": 728, "height": 90,
          "rotation": 0, "opacity": 1,
          "fills": [...], "strokes": [...],
          "clipsContent": false
        },
        {
          "id": "123:458",
          "type": "TEXT",
          "characters": "Hello World",
          "fontSize": 24,
          "fontName": { "family": "Inter", "style": "Bold" },
          "fontWeight": 700,
          "textAlignHorizontal": "LEFT",
          "textAlignVertical": "TOP"
        }
      ]
    }
  ],
  "images": {
    "imageHash123": "<base64>",
    "node_456": "<base64>"
  }
}
```

## Supported Node Types

| Figma Node Type | Export Method |
|----------------|---------------|
| RECTANGLE | Native CSS (fills, strokes, corner radius, effects) |
| ELLIPSE (full) | Native CSS (border-radius: 50%) |
| ELLIPSE (arc/donut) | Rasterized PNG — CSS cannot represent partial arcs |
| TEXT | Full typography + character data |
| VECTOR | Rasterized PNG |
| STAR | Rasterized PNG |
| LINE | Rasterized PNG |
| POLYGON | Rasterized PNG |
| BOOLEAN_OPERATION | Rasterized PNG |
| FRAME | Recursive — children exported; clips when `clipsContent: true` |
| GROUP | Recursive — children exported; never clips |
| INSTANCE | Recursive — children exported |
| COMPONENT | Recursive — children exported |

## Advantages Over REST API

| Feature | Plugin | REST API |
|---------|--------|----------|
| Rate Limits | None | 15/min |
| Authentication | Not needed | Token required |
| Network | Not needed | Required |
| CORS | N/A | Proxy needed |
| Access | Full document | Limited |
| Speed | Instant | Multiple requests |

## Known Limitations

- Requires Figma Desktop App (web version has limited plugin support)
- Auto Layout constraints are not preserved — absolute positioning only
- Animations and interactions are not exported
- Mixed text styles (runs with different fonts/sizes within one text node) render using the dominant style
- HTML output uses system fonts when the exact Figma font is not available on the viewer's machine
- Plugins/widgets are not included

## Development

### Project Structure

```
figma-plugin/
├── manifest.json       # Plugin metadata
├── code.ts             # Plugin logic (TypeScript) — runs in Figma sandbox
├── code.js             # Compiled output (generated by tsc)
├── ui.html             # Plugin UI + HTML export generator
├── package.json
├── tsconfig.json
└── README.md
```

### Making Changes

1. Edit `code.ts` for plugin/export logic
2. Edit `ui.html` for UI and HTML generation changes
3. Run `npm run build` to compile
4. Reload in Figma: Plugins → Development → Reload plugin

### Debugging

- `console.log()` in `code.ts` → Figma Desktop console (Help → Toggle Developer Tools)
- `console.log()` in `ui.html` → Plugin UI console (right-click plugin → Inspect)
